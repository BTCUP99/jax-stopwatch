无线组网 检查中

拔掉 USB 后，设备经家里 Wi-Fi 或手机热点主动连回这台 Mac。公网只开放设备入口，控制台不对外。每台设备有独立密钥（只经 USB 写入），丢失时在这里停用。

插 USB 配对无线（写入 Wi-Fi 和设备密钥）

最多 4 个网络，设备按顺序尝试；Wi-Fi 栏全部留空则保留设备里已保存的网络，只更新密钥和局域网证书。手机热点请开启“最大化兼容性”（设备只支持 2.4GHz）。密码只经 USB 写入设备，Mac 不保存。重新配对会停用这台设备之前的密钥。

形象管理 检查中

形象来自项目的 avatars/ 目录（制作规范见 docs/avatars.md）。上传会转成 JPEG 并经 USB 写入设备、逐个文件校验；切换即时生效，无线连接时也能切换；也可以直接在手表首页左右滑动切换（固件 0.5.0）。任务完成和 X 提醒播报结束后，会短暂显示该形象的开心表情。
