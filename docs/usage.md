# 日常使用

设备亮屏、能连上 Mac（USB 或无线）时直接按键就能用。控制台 <http://127.0.0.1:18765> 只在需要查看、调试、审批时打开；关闭网页不会停止后台。

## 按键

| 操作 | 效果 |
|---|---|
| **按住 A** | 讲话，松开发送。靠近麦克风说完整短句，单次最多 30 秒。 |
| **单击 B** | 切换 Codex / Webhook 助手，会播报名称，屏幕底部同步显示。 |
| **双击 B** | 停止本机处理和播报。已派发给云端 Agent 的任务需要到对应平台取消。 |
| 长按 B | 打开设备设置菜单（默认 Audio 音量页）；单击 A 或再长按 B 退出。 |
| 单击电源键 | 熄屏。熄屏会断开与 Mac 的连接、关闭 Wi-Fi 省电，收不到提醒；短按电源键或单击 B 唤醒后自动重连。 |

也可以在一句话开头直接指定助手：“让 Codex……”“让 Grok……”。这是 Mac 本地的规则匹配，不经过模型。

## 首页

![首页面板](images/home-screen.png)

| 位置 | 含义 |
|---|---|
| 顶部 | 时间（连上 Mac 时自动校准）。 |
| 底部状态栏 | 当前助手（绿色 Codex / 灰白 Grok）、连接图标、电量。上方一排小圆点是形象页码：一共几套、当前第几套（只有一套时不显示）。 |
| 右侧 | X 提醒图标，每条 30 分钟后消失，同类多条显示数量。图标还在时**摇一摇手表**可重播最新一条。 |
| 说话时 | 字幕气泡，最后一句播完停留约 5 秒；形象随音量张嘴、会眨眼。 |
| 任务完成 | 当前形象的开心表情显示 2 秒。 |
| 左右滑动 | 切换到下一套 / 上一套形象（向左滑是下一套），滑到位的一瞬间短振一下表示已触发；状态栏上方的小圆点显示当前是第几套；内置形象也在其中，循环切换，不需要连着 Mac。 |
| 触摸形象 | 待机时轻点“嘻嘻”调皮，快速连点三下“哈哈”大笑（只有表情、不出声）。形象没有触摸帧时显示开心表情；控制台“形象管理”可关闭。 |

### 连接图标

![连接与提醒图标](images/status-icons.png)

| 图标 | 状态 |
|---|---|
| 浅蓝插头 | USB 有线连接 |
| 绿色 Wi-Fi | 局域网直连 Mac（最快） |
| 蓝色 Wi-Fi + 地球 | 经公网入口连接（语音会压缩） |
| 灰色 Wi-Fi | 正在连接 |
| Wi-Fi + 红 × | 附近没有已保存的 Wi-Fi |
| Wi-Fi + 橙 ! | Wi-Fi 正常但连不上 Mac（Mac 关机、后台未运行或外网断开） |
| 不显示 | 刚开机或刚拔线约 10 秒内，正在判断走有线还是无线 |

本版关闭了上游的好感度、步数显示、随倾斜转头、摇晃晕眩与振动，以减少干扰；上游的摸头动画换成了上面的触摸表情。

## 换形象

> 存储空间：三套自带形象连同触摸表情共占设备约 1.2MB，装好后约剩 2.2MB，还能放 4–7 套自制形象，详见[容量参考](avatars.md#8-容量参考)。从 0.3.x 升级后，已上传的形象需要插 USB 点一次“重新上传”，才会带上触摸表情（不重传也能用，触摸时显示开心表情）。

插 USB，控制台“形象管理”里点某套形象的 **上传并使用**，约 20 秒写入设备；已上传的形象随时点 **使用** 切换（无线时也行），或者直接在手表首页左右滑动，立即生效、重启后保持。点 **内置形象** 恢复上游默认脸。自己做形象见 [形象制作规范](avatars.md)，放进 `avatars/<id>/` 后控制台自动列出。

## 好用的语音指令

按“**做什么 → 对哪个文件或主题 → 输出到哪里 → 播报多长**”说清楚。较长回答只播报前约 360 字，完整内容在控制台。

> “在工作区新建今天的待办，写上整理素材、检查备份、准备明天的会议。”
>
> “写一个 Python 脚本，统计工作区有多少个文本文件。先保存，不要执行。”
>
> “让 Grok 帮我拟一段会议开场白，五十字以内，直接读给我听。”

Codex 需要权限的操作会在控制台弹出审批，不会自动放行。

## 音量与声音

- 音量：任务结束后长按 B 进入 **Audio**，点 Volume 下方的 − / ＋（0–255，保存在设备里）。
- 播报声音和语速：控制台“播报声音”卡片，可在设备上试听再保存。

## 排障

| 现象 | 处理 |
|---|---|
| 控制台打不开 | 运行 `scripts/start.command`；仍失败看 `runtime/bridge.log`。 |
| 插着 USB 却没有插头图标 | 确认是数据线、设备亮屏；控制台是否显示“设备已连接”，必要时重启后台。 |
| 拔线后一直灰色或橙 ! | 确认 Mac 开机、后台在运行；在外确认外网正常。插回 USB 看控制台“无线组网”的最近连接记录。 |
| 红 × | 打开手机热点（2.4GHz），或插 USB 添加新网络。 |
| 在外播报断续 | 公网路径延迟较高，属正常范围；回家后自动切回局域网。 |
| 有字幕没声音 | 长按 B 进 Audio，确认 Volume 大于 0。 |
| 识别错了 | 靠近麦克风、一次一句、说完再松开；也可在控制台用文字发送。 |
| Webhook 助手一直等待 | 先到 Agent 平台看是否在等审批或仍在运行，不要立即重复发送。 |
| 没收到 X 提醒 | 设备要亮屏且已连接；控制台“X 提醒”应显示“实时接收中”。 |
| 首页是几何脸 | 设备 LittleFS 里没有内置图片：上传一套形象，或用 `flash.sh --first-install` 重装。 |

## 设备菜单（长按 B）

| 页面 | 用途 |
|---|---|
| Display | 屏幕亮度 |
| Audio | 扬声器音量 |
| Power | 电量、温度、外接供电、Low Power |
| Steps | 计步记录（首页不显示步数） |
| StreetPass | 附近同类设备的蓝牙资料交换（上游功能） |
| Network | 上游的旧网络页，**不反映本项目的无线状态**，以首页图标和控制台为准 |
