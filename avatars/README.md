# 形象

每个文件夹是一套形象：16 张基础帧 `base_m{嘴0-3}_e{眼0-3}.png`、开心表情 `happy.png`、描述 `avatar.json`，以及预览图 `preview.png`（4×4 拼图，行 = 嘴，列 = 眼）和 `happy-preview.png`。制作规范见 [docs/avatars.md](../docs/avatars.md)。

| | 形象 | 设定 |
|---|---|---|
| <img src="nuo-courier/base_m0_e0.png" width="96"> | **糯邮** `nuo-courier` | 暖心口袋信使。奶油糯米团身体、单侧软信笺折角、杏橙透明通知口袋和薄荷消息光种。“把你的消息轻轻收好，再笑着交给你。” |
| <img src="orbit-warden/base_m0_e0.png" width="96"> | **弦核** `orbit-warden` | 安静的星际小法师。偏心冰青开放轨道、靛蓝菱形面罩、悬浮金白菱核与白紫双层掠翼。“替你守住每一束信号。” |
| <img src="little-host/base_m0_e0.png" width="96"> | **小主播** `little-host` | 青蓝短发、粉色方框眼镜、金色耳饰与彩条西装的主持人。 |

三套形象以 MIT License 随仓库发布，可以自由使用和修改。新形象欢迎提 PR：放一个新文件夹，附上 `preview.png`，并在 PR 里说明来源（原创或可再分发的授权）。
